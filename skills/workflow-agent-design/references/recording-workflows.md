# 화면 시연으로 업무 파악하기

녹화는 설명이 어려운 UI 업무를 보조하는 선택지다. 기록만으로 업무 규칙·예외·승인 기준을 추정하지 말고, 빠진 의미는 한 번에 하나씩 질문한다. 녹화 전 현재 앱, 요금제, 운영체제, 녹화 기능과 화면·손쉬운 사용 권한을 확인한다. 기능이 없거나 사용자가 원하지 않으면 인터뷰를 계속한다.

## Codex Record & Replay

- 사용자가 시연할 준비가 됐을 때만 `event_stream_start`를 호출한다.
- 시작 성공 후 폴링·sleep·반복 대기를 하지 않는다. 그 턴을 종료하며, 녹화는 최대 30분이고 끝나면 돌아와 알려 달라고 안내한다.
- 사용자가 상태를 묻거나 녹화 후 돌아온 경우에만 상태를 확인한다.
- 완료했다고 하면 `event_stream_stop`을 호출하고 반환된 `metadataPath`와 `eventsPath`를 파일 도구로 직접 읽는다. 이벤트 파일을 주 근거로 삼는다.
- 취소했다면 다시 stop하지 않고 기록을 사용하거나 스킬을 만들지 않는다. 필요할 때만 세션 종료 사유를 확인한다.
- 동시에 활성 녹화가 있으면 재시작하지 않고 기존 녹화를 사용할지 확인한다.

비밀번호, OTP, API 키, 신분·금융·의료·법률·인사 정보는 결과와 생성 스킬에서 제거하거나 일반화한다. 녹화는 의도와 실제 화면 흐름의 증거이지 모든 클릭을 복제하라는 지시가 아니다. 연결 툴을 우선하고, 불가피한 UI 조작도 좌표보다 앱·창·컨트롤과 결과 검증을 사용한다.

완료 녹화가 재사용 흐름과 입력을 충분히 보여 주면 요약에서 멈추지 말고 [skill-generation.md](skill-generation.md)에 따라 실제 스킬을 만든다. 공식 프로젝트 발견 경로를 쓸 수 있으면 발견 가능한 스킬까지 생성하고, 정본만 만들 수 있으면 앱 인식을 `미수행`으로 기록한다.

## Claude Cowork의 Record a skill

[Claude 공식 지원 문서](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills)에 따라 현재 지원 여부를 다시 확인한다. 2026-11-07 확인 기준으로 Mac의 Cowork에서 Pro, Max, Ultra, Team 요금제에 제공되며 약 10분의 시연으로 스킬을 만들 수 있다. 일반 Chat, Windows, Free, Enterprise에서는 지원되지 않는다.

Claude에서는 해당 앱의 `Record a skill` 흐름을 안내한다. Claude에게 Codex의 `event_stream_*` 도구를 호출하라고 지시하지 않는다. 녹화가 끝나면 생성 초안에서 고정값·민감값·UI 좌표를 제거하고 업무 규칙과 예외를 사용자에게 확인한 뒤 실제 발견 가능한 스킬로 만들고, 이 설계의 단계 ID와 검증 기준에 맞춰 정본과 상태를 기록한다.

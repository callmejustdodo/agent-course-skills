# 수강생용 에이전트 스킬 모음

강의에서 바로 사용할 수 있는 인터뷰형 스킬을 모으는 저장소입니다. 수강생이 빈 양식이나 긴 프롬프트를 직접 쓰지 않고, AI의 질문에 자기 업무를 설명하면서 결과를 만들도록 설계합니다.

## 스킬 목록

### [`workflow-agent-design`](skills/workflow-agent-design/SKILL.md) · 업무 흐름·에이전트 설계 코치

내 담당 업무를 처음부터 끝까지 펼치고, 단계별 조건·예외·사람 판단을 확인합니다. AI가 공식 자료를 조사해 수동 처리·규칙·툴과 실행 환경을 함께 결정한 뒤, 기존 스킬로 처리되지 않는 반복 업무는 실제 SKILL.md로 만들고 검증합니다.

다음처럼 시작할 수 있습니다.

> `$workflow-agent-design`을 사용해서 내 업무를 처음부터 끝까지 정리하고, 도구·실행 환경을 결정한 뒤 필요한 업무 스킬을 만들어 검증해 줘.

## 설치

이 저장소 URL을 Codex 또는 Claude에 주고 다음처럼 요청하는 방식을 권장합니다.

> https://github.com/callmejustdodo/agent-course-skills 의 `skills/workflow-agent-design`을 확인하고, 현재 사용 중인 앱의 공식 사용자 스킬 설치 위치를 먼저 확인해 줘. 기존 파일을 덮어쓰지 말고 설치한 뒤, 실제로 스킬 목록에서 인식되는지 검증해 줘.

설치 위치와 지원 방식은 앱·버전에 따라 달라질 수 있으므로 에이전트가 현재 환경과 공식 문서를 확인하게 합니다. 저장소를 복제해도 스킬이 자동 설치되는 것은 아닙니다.

## 사용 결과

스킬은 현재 작업공간의 `company-agent/` 아래에 다음을 이어서 기록합니다.

- `workflow-map.md`: 업무 범위와 단계별 전체 흐름
- `agent-design-decisions.md`: 단계별 툴·스킬·실행 환경의 추천과 합의
- `workflow-design-state.md`: 진행 상태, 미분석 업무, 다음 질문과 파일럿
- `skills/<name>/SKILL.md`: 합의된 업무를 수행하는 스킬 정본
- `skill-verification.md`: 구조·모의 실행·앱 인식·실제 업무 검증 상태

공식 프로젝트 스킬 위치를 확인할 수 있으면 현재 작업공간 안에 발견 가능한 스킬도 함께 만듭니다. `company-agent/skills/`의 정본만으로는 자동 설치됐다고 간주하지 않습니다. 사용자 프로필 설치·구매·계정 설정·외부 시스템 변경·배포는 별도 요청이 필요합니다.

화면으로 보여 주는 편이 빠른 업무는 사용자가 원하고 앱에서 지원할 때만 녹화를 보조 수단으로 쓸 수 있습니다. 녹화가 없어도 인터뷰 방식으로 계속 진행합니다.
